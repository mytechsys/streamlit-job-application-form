# Streamlit Job Application Form

A simple Streamlit app to collect job application details: name, email, mobile number, and state.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Cloud

1. Push this repo to GitHub.
2. Go to https://share.streamlit.io
3. Connect your repo and select `app.py`.
4. Deploy.

## Notes

- Submissions are saved to `job_applications.csv` in the app folder.
- This is a lightweight demo for collecting basic application data.
